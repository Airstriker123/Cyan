HOW TO USE TOOL:
1. Extract the zip file
2. Open setup.bat (windows defender says it protected your pc because it is a batch file and it is 100% safe)
3. cyan tool should open once setup is finished
4. input the corresponding number listed to the menu option e.g. "1" and press enter to execute.
5. enjoy!


NOTE: once you open setup once you do not have to open it again and can just open cyan.py!

NOTE: YouTube video (mp3/mp4) downloader might not work on the school
network! (most likely because of proxy so use it on your own network and it should work fine.)

Note: Tool made in python with exception of calendar made using python backend (flask) and HTML&CSS frontend.
